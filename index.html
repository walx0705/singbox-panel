install 与 rep 的区别：rep 会按当前表单的端口重组配置，但密码 / UUID / Reality 密钥沿用机器上已保存的，不会把已导入的客户端弄失效。list / status / stop / del 不需要填端口。

    

  






  命令指向自己的仓库脚本 sb.sh（数据存目标机 ~/sb-node，日志 sing-box.log）。脚本不内置任何密码，密码与密钥都在目标机器上生成并保存。

  有 systemd 的机器用 systemd 托管；无 systemd 的沙盒（如 Altare）自动用 nohup 托管，重启后跑一次 install 或 start 即可恢复。
